# 윤재 루틴

윤재의 아침 등교 루틴 대시보드 — GitHub Pages에서 바로 열 수 있는 정적 페이지입니다.

- https://stolberry.github.io/yunjae-morning-dashboard/

## 구성

- **대시보드** (태블릿 한 화면용 배치): 위에서부터 오늘의 확언 띠 → 왼쪽 08:15 등교 카운트다운 →
  오른쪽 오늘의 학원 스케줄·오늘의 공부(둘 다 홈에서 바로 체크)·천안 날씨 띠 → 맨 아래 6단계 아침 루틴 카드
- **학원 스케줄**: 월~일 주간 스케줄 추가/수정/삭제
- **공부**: 요일별 공부(숙제 · 월·수·금 빅박스·화상영어 · 화·목 사고력수학 · 화·수·금·토·일 피아노연습) 체크
- **포켓몬 도감**: 루틴·공부 완료로 몬스터볼을 모아 뽑기 (도감 수집)
  - 일반 뽑기 10개 / 슈퍼 뽑기 18개(진화·전설 확률↑) / 마스터 뽑기 30개(전설·메가 100%)
  - 60마리 (일반·진화·전설·메가진화)
  - 진화: 💎 진화의 돌 1개 (일반 진화) / 2개 (메가진화)
  - 진화의 돌: 아침 루틴+공부를 100% 다 한 날이 3일 연속이 될 때마다 1개 (3·6·9일…)

## 파일

- `index.html` — 전체 앱 (HTML/CSS/JS 한 파일)
- `assets/routine-*.png` — 6단계 루틴 그림
- `assets/icon-*.png`, `manifest.json`, `sw.js` — 홈 화면에 추가(PWA)용
- 검색엔진에는 노출되지 않도록 `noindex,nofollow` 설정

## 저장되는 것 (브라우저 localStorage)

루틴 체크(`yj_routine_done_v1`), 루틴 목록(`yj_routine_items_v3`), 학원(`yj_academies_v1`),
공부 주간표(`yj_homeschool_tasks_v1`), 공부 체크(`yj_homeschool_done_v1`),
몬스터볼(`yj_balls_v1`), 도감(`yj_dex_v1`), 보상 기록(`yj_awards_v1`),
완벽한 날(`yj_perfect_days_v1`), 진화의 돌(`yj_stones_v1`, `yj_stone_awards_v1`).

예전 기본 목록(4개·5개 루틴)이 저장돼 있으면 새 6개 목록으로 자동으로 올라가고,
같은 이름의 체크 기록은 그대로 이어집니다. 공부 주간표도 예전 기본값(원리셈·따풀, 리틀팍스 포함)이면
새 기본값(숙제 + 요일별)으로 자동으로 바뀝니다.
