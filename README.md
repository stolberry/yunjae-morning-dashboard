# 윤재 루틴

윤재의 아침·저녁 루틴 대시보드 — GitHub Pages에서 바로 열 수 있는 정적 페이지입니다.

- https://stolberry.github.io/yunjae-morning-dashboard/

## 구성

- **아침 / 저녁 자동 전환**: 00:00–17:29는 **🌅 아침**, 17:30–23:59는 **🌙 저녁** 화면이 자동으로 열립니다.
  상단의 **🌅 아침 / 🌙 저녁** 버튼으로 언제든 1탭 전환할 수 있어요 (직접 고른 화면은 새로고침 전까지 유지).
- **아침 대시보드**: 왼쪽(약 2/3) **날짜·요일 + 큰 현재 시계** 카드, 그 아래 **등교 시간(08:15)** 카드 —
  남은 시간이 줄어드는 초록 막대와 `07:00 기상 · 07:10 아침식사 · 07:30 양치 · 07:45 원리셈 · 08:15 등교`
  마일스톤, 오른쪽(약 1/3)에 **오늘의 확언·날씨·오늘의 학원 스케줄**을 컴팩트하게, 맨 아래 **아침 루틴 6단계**.
- **저녁 대시보드**: 왼쪽 **날짜·시간 + 취침 시간(21:00)** 카드 — 저녁 파스텔 테마, 21:00까지 남은 시간과
  17:30→21:00 진행 막대 + `17:30 샤워 · 18:00 저녁식사 · 18:30 숙제 · 20:00 가방정리·양치 · 21:00 취침` 마일스톤,
  저녁 루틴 n/5·몬스터볼·도감 가기. 오른쪽에 **오늘의 확언·날씨·오늘의 공부**(항목마다 +1), 맨 아래 **저녁 루틴 5단계**.
- **알림**: 07:00·07:10·07:30·07:45·08:15 / 17:30·18:00·18:30·20:00·21:00 정각에 부드러운 차임과
  `⏰ 7:10 아침식사 시간이에요!` 배너가 하루 한 번 뜹니다 (효과음이 켜져 있을 때). `🔔 알림 테스트` 버튼으로 미리 확인할 수 있어요.
- **학원 스케줄**: 월~일 주간 스케줄 추가/수정/삭제 — 시작 시간이 이른 순서대로 보여 주고
  시간은 `오후 2:00 ~ 3:00`처럼 아이가 읽기 쉬운 12시간 표기로 표시 (저장은 `HH:MM` 그대로)
- **공부**: 요일별 공부(숙제 월~금 · 일요일 그림일기 · 월·수·금 빅박스·화상영어 · 화·목 사고력수학 · 피아노연습 매일) 체크
- **포켓몬 도감**: 루틴·공부 완료로 몬스터볼을 모아 뽑기 (도감 수집)
  - 일반 뽑기 10개 / 슈퍼 뽑기 25개 / 마스터 뽑기 50개(전설·메가 100%)
  - 60마리 (일반·진화·전설·메가진화)
  - 진화: 💎 진화의 돌 1개 (일반 진화) / 2개 (메가진화)

## 몬스터볼 보상 규칙

- **아침 1~5번**(세수·로션 / 유산균·물 마시기 / 아침먹으면서 영어영상 / 용변·양치 / 옷입고 양말신기)
  은 **체크만** 합니다. 5개를 모두 체크하면 *"아침 생활 루틴 5개를 모두 다 했어요?"* 를 물어보고
  **네**를 누르면 **몬스터볼 +1**. 5개 중 하나라도 체크를 풀면 그 1개를 회수합니다.
- **아침 6번 원리셈·따풀**은 따로: 누르면 *"원리셈·따풀 다 했어요?"* → **+1** (체크를 풀면 회수).
- **저녁 5단계**(샤워 / 저녁식사 / 숙제·공부 / 양치·가방정리 / 독서)도 **체크만**.
  5개를 모두 체크하면 *"저녁 루틴 5개를 모두 다 했어요?"* → **+1** (하나라도 풀면 회수).
  예전 7단계 기본 목록을 쓰던 브라우저는 자동으로 5단계로 바뀌고 체크도 이어집니다.
- **오늘의 공부**는 항목마다 +1 (확인 창 · 체크를 풀면 회수). `📚 공부` 탭과 같은 기록을 씁니다.
- **100% 완벽한 날** = 아침 6/6 + 저녁 5/5 + 오늘의 공부 모두. 3일 연속이면 **💎 진화의 돌 1개**.

## 파일

- `index.html` — 전체 앱 (HTML/CSS/JS 한 파일)
- `assets/routine-*.png` — 아침 루틴 그림
- `assets/evening-*.png` — 저녁 루틴 그림 (양치는 `routine-brush.png` 재사용)
- `assets/icon-*.png`, `manifest.json`, `sw.js` — 홈 화면에 추가(PWA)용
- 검색엔진에는 노출되지 않도록 `noindex,nofollow` 설정

## 저장되는 것 (브라우저 localStorage)

아침 체크(`yj_routine_done_v1`), 아침 목록(`yj_routine_items_v3`),
저녁 체크(`yj_evening_done_v1`), 저녁 목록(`yj_evening_items_v1`),
학원(`yj_academies_v1`), 공부 주간표(`yj_homeschool_tasks_v1`), 공부 체크(`yj_homeschool_done_v1`),
몬스터볼(`yj_balls_v1`), 도감(`yj_dex_v1`), 보상 기록(`yj_awards_v1`),
완벽한 날(`yj_perfect_days_v1`), 진화의 돌(`yj_stones_v1`, `yj_stone_awards_v1`).

예전 기본 목록(4개·5개 루틴)이 저장돼 있으면 새 6개 목록으로 자동으로 올라가고,
같은 이름의 체크 기록은 그대로 이어집니다. 공부 주간표도 예전 기본값(원리셈·따풀, 리틀팍스 포함)이면
새 기본값(숙제 + 요일별)으로 자동으로 바뀝니다.
