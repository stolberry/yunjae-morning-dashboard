# 윤재 루틴

윤재의 아침·저녁 루틴 대시보드 — GitHub Pages에서 바로 열 수 있는 정적 페이지입니다.

- https://stolberry.github.io/yunjae-morning-dashboard/

## 구성

- **오전 / 오후 자동 전환**: 00:00–17:29는 **☀️ 오전**, 17:30–23:59는 **🌇 오후** 화면이 자동으로 열립니다.
  상단의 **☀️ 오전 / 🌇 오후** 버튼으로 언제든 1탭 전환할 수 있어요 (직접 고른 화면은 새로고침 전까지 유지).
- **오전 대시보드**: 왼쪽 60% 칸은 맨 위 **등교 시간(08:15) 히어로 카드**
  (남은 시간이 줄어드는 초록 막대와 `7:00 기상 · 7:10 식사 · 7:30 양치 · 7:45 원리셈 · 8:15 등교` 한 줄 마일스톤,
  윤재 옆 배지는 하루 종일 **솔가레오**), 그 아래 **오전 루틴 6단계**가 **3열 × 2행**으로 들어갑니다.
  오른쪽 40% 칸은 위에서부터 **📅 날짜·시간 막대**, **날씨 막대**, **📅 오늘의 스케줄**, **🌟 특급칭찬 막대**, **🔥 MISSION**(원리셈·따풀·지각 안하기).
- **솔가레오 · 루나아라의 여정**: 오전엔 **솔가레오**가 윤재 옆 배지에 앉아 있고, **07:10**이 되면 진행 막대 위로 올라가
  8:15 등교까지 함께 달립니다(도착해도 그대로). 오후엔 **루나아라**가 배지에 있다가 **17:30**부터 21:00 취침까지 막대 위를 달립니다.
  둘 다 **진화하지 않고** 하루 종일 같은 모습이에요 (08:15 진화 연출·20:00 잠만보 교체는 없어졌습니다).
- **저녁 대시보드**: 왼쪽 60% 칸은 맨 위 **취침 시간(21:00) 히어로 카드** — 저녁 파스텔 테마, 21:00까지 남은 시간과
  17:30→21:00 진행 막대 + `5:30 샤워 · 6:00 식사 · 6:30 숙제 · 8:00 정리·양치 · 9:00 취침` 마일스톤,
  오후 루틴 n/6·몬스터볼·도감 가기 — 그 아래 **오후 루틴 6단계**가 **3열 × 2행**.
  오른쪽 40% 칸은 위에서부터 **📅 날짜·시간 막대**, **🌱 생활습관**, **🔥 MISSION**(오늘 할 일 · 포켓몬 카드),
  **🎲 랜덤 보너스 뽑기**(맨 아래 — 누르면 오늘의 보너스가 뽑히는 룰렛 배너).
- **알림**: 07:00·07:10·07:30·07:45·08:15 / 17:30·18:00·18:30·20:00·21:00 정각에 부드러운 차임과
  `⏰ 7:10 아침식사 시간이에요!` 배너가 하루 한 번 뜹니다 (효과음이 켜져 있을 때). `🔔 알림 테스트` 버튼으로 미리 확인할 수 있어요.
- **학원 스케줄**: 월~일 주간 스케줄 추가/수정/삭제 — 시작 시간이 이른 순서대로 보여 주고
  시간은 `오후 2:00 ~ 3:00`처럼 아이가 읽기 쉬운 12시간 표기로 표시 (저장은 `HH:MM` 그대로)
- **🔥 미션 탭**: 상단 탭 `🔥 미션`에서 요일별 오늘의 미션(`+ 미션 추가`, ↑/↓ 순서)·⚡ 보너스 관리·🌱 생활습관을 한곳에서 고칩니다.
  같은 탭의 **🔥 오전 미션** 카드에 평일(월~금)·주말(토·일) 미션이 미리 보이고,
  `⚙️ 오전 미션 편집 (평일·주말)`을 누르면 오전 화면의 🔥 MISSION 목록을 바로 고칠 수 있어요.
- **공부**: 요일별 공부(원서 낭독·피아노연습 매일 · 일요일 그림일기 · 월·수·금 빅박스·화상영어 · 화·목 사고력수학) 체크
- **🌟 칭찬**: 엄마가 4자리 비밀번호를 넣고 **🌟 특급칭찬**을 남기면 몬스터볼 **+5**,
  칭찬 내용은 **🌟 칭찬** 탭에 날짜·시간과 함께 차곡차곡 쌓입니다 (비밀번호 변경·기록 지우기도 엄마만)
- **포켓몬 도감**: 루틴·공부 완료로 몬스터볼을 모아 뽑기 (도감 수집)
  - 일반 뽑기 10개 / 슈퍼 뽑기 25개 / 마스터 뽑기 50개(전설·메가 100%)
  - 82마리 (일반·진화·전설·메가진화) · 무한다이노 포함
  - 진화: 💎 진화의 돌 1개 (일반 진화) / 2개 (메가진화)
    이브이는 샤미드·쥬피썬더·부스터·블래키·님피아 **5가지 모습**으로 진화할 수 있어요
  - 🔄 **놓아주기**: 도감에서 잡은 포켓몬을 누르면 상세 창에서 **🔄 놓아주기 (+N볼)** —
    놓아주면 잡을 때 쓴 몬스터볼의 **절반**(내림)을 돌려받아요
    (일반·진화 10볼 → +5 / 전설·메가진화 50볼 → +25, 예전 기록은 등급 기본값으로 계산)

## 몬스터볼 보상 규칙

- **아침 6단계**(잠자리 정리 / 세수·로션 / 유산균·물 마시기 / 아침식사·영어영상 / 용변·양치 / 옷입고 양말신기)
  는 **체크만** 합니다. 6개를 모두 체크하면 *"아침 생활 루틴 6개를 모두 다 했어요?"* 를 물어보고
  **네**를 누르면 **몬스터볼 +1**. 6개 중 하나라도 체크를 풀면 그 1개를 회수합니다.
- **원리셈·따풀·지각 안하기**는 아침 루틴 카드가 아니라 오른쪽 **🔥 아침 미션** 카드에 있어요. 누르면
  *"원리셈 다 했어요?"* · *"오늘 지각 안 했어요?"* 처럼 한 번 물어보고 **+1** (체크를 풀면 회수).
  세 장 모두 카드가 3D로 뒤집히며 몬스터볼이 톡 튀어나옵니다. `지각 안하기`는 날마다 새로 시작해요.
- **저녁 6단계**(신발정리·옷정리 / 샤워 / 저녁식사 / 숙제·공부 / 양치·가방정리 / 독서)도 **체크만**.
  6개를 모두 체크하면 *"저녁 루틴 6개를 모두 다 했어요?"* → **+1** (하나라도 풀면 회수).
  예전 5·7단계 기본 목록을 쓰던 브라우저는 자동으로 6단계로 바뀌고 체크도 이어집니다.
- **✅ 오늘 꼭 할 일**은 항목마다 +1 (확인 창 · 체크를 풀면 회수). `🔥 미션` 탭과 같은 기록을 씁니다.
- **🎲 랜덤 보너스 뽑기**(리딩앤 3권 · 영어 글쓰기 · 그림일기 · 독후감)는 **하고 싶을 때만** 하는 선택 과목이에요.
  오후 홈의 그림 배너를 누르면 이름이 약 1.1초 돌아가다 **한 가지가 뽑히고**, `✓ 완료`를 누르면 **+1**
  (하루 3개까지, `🔄 다시 돌리기`는 하루 3번까지 — 버튼에 남은 횟수가 보이고 0이 되면 눌리지 않아요).
  칸마다 **처음 뽑기는 공짜**이고, `🔄 다시 돌리기`만 1번씩 씁니다 (날짜가 바뀌면 다시 3번).
  보너스는 **100% 완벽한 날 조건에 들어가지 않아요** (아침 6/6 + 원리셈·따풀 + 저녁 6/6 + 오늘 꼭 할 일만).
- **🌱 생활습관 미션**은 이번 주에 집중할 습관 **1~3개**(기본: ⏰ 알람 울리면 바로 일어나기 · 🍽️ 다 먹은 그릇 싱크대에 두기).
  매일 체크하면 **🔥 연속 일수**가 쌓이고, 습관마다 **3일 연속 달성할 때마다**(3·6·9일…) **💎 진화의 돌 +1** — 당연한 일이라 **몬스터볼은 주지 않습니다**.
  같은 날 같은 습관으로 돌을 두 번 받지 않고, 오늘 받은 돌은 그 체크를 풀면 함께 돌아갑니다.
  아침·저녁 화면과 🔥 미션 탭에 같은 기록으로 보이고, `⚙️ 습관 편집`에서 이름·순서·추가·삭제를 할 수 있어요.
- **지각 안하기** 미션은 자기 몫의 +1 만 하고, 완벽한 날·공부 올클리어 조건에는 들어가지 않아요.
- **🌟 특급칭찬**은 엄마가 비밀번호를 넣고 칭찬을 남기면 **몬스터볼 +5**, 칭찬 내용은 `🌟 칭찬` 탭에 쌓입니다.
- **💎 진화의 돌**: 100% 완벽한 날(아침 6/6 + 원리셈·따풀 + 저녁 6/6 + 오늘의 공부 모두) **3일 연속마다 1개**, 그리고 **생활습관 하나를 3일 연속 달성할 때마다 1개**.

## 파일

- `index.html` — 전체 앱 (HTML/CSS/JS 한 파일)
- `assets/routine-*.png` — 아침 루틴 그림 (`routine-bed.png` = 잠자리 정리, `routine-shoes-clothes.png` = 신발정리·옷정리)
- `assets/mega-charizard-x-10034.png` — 메가리자몽X (배지·막대 결승점)
- `assets/charizard-6.png` — 리자몽 (배지·07:10부터 막대 위에서 달림)
- `assets/snorlax-143.png` — 잠만보 (저녁 20:00부터 진행바에서 취침을 향해)
- `assets/evening-*.png` — 저녁 루틴 그림 (양치는 `routine-brush.png` 재사용)
- `assets/icon-*.png`, `manifest.json`, `sw.js` — 홈 화면에 추가(PWA)용
- 검색엔진에는 노출되지 않도록 `noindex,nofollow` 설정

## 저장되는 것 (브라우저 localStorage)

아침 체크(`yj_routine_done_v1`), 아침 목록(`yj_routine_items_v3`),
저녁 체크(`yj_evening_done_v1`), 저녁 목록(`yj_evening_items_v1`),
학원(`yj_academies_v1`), 공부 주간표(`yj_homeschool_tasks_v1`), 공부 체크(`yj_homeschool_done_v1`),
몬스터볼(`yj_balls_v1`), 도감(`yj_dex_v1`), 도감 볼 값(`yj_dex_costs_v1`), 보상 기록(`yj_awards_v1`),
완벽한 날(`yj_perfect_days_v1`), 진화의 돌(`yj_stones_v1`, `yj_stone_awards_v1`),
엄마 비밀번호(`yj_mom_pin_v1`), 특급칭찬 기록(`yj_praises_v1`),
공부표 ‘원서 낭독’ 이전 기록(`yj_study_migrated_reading_v1`), 보너스 공부 체크(`yj_bonus_done_v1`),
보너스 뽑기(`yj_bonus_pick_v1`)·다시 돌리기 횟수(`yj_bonus_reroll_v1`),
오전 미션 목록(`yj_morning_missions_v1`),
아침 미션 ‘지각 안하기’ 체크(`yj_morning_mission_done_v1`), 생활습관 목록(`yj_habits_v1`)·체크(`yj_habit_done_v1`),
루틴 6단계 마이그레이션 플래그(`yj_routines_v6_migrated`).

예전 기본 목록(4개·5개 루틴)이 저장돼 있으면 새 6개 목록으로 자동으로 올라가고,
같은 이름의 체크 기록은 그대로 이어집니다. 저장된 목록에 `잠자리 정리`(아침)·`신발정리·옷정리`(저녁)가 없으면
맨 앞에 한 번만 넣어 주고(직접 고친 목록은 그대로), 공부 주간표도 예전 기본값(원리셈·따풀, 리틀팍스 포함)이면
새 기본값(숙제 + 요일별)으로 자동으로 바뀝니다.
